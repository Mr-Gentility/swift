## 📌 About Swift

**Swift Logistics** is a PHP and MySQL-powered logistics platform designed for courier companies, dispatch businesses, delivery services, and shipment management operations.

The system provides a centralized environment for managing shipments, tracking delivery progress, administering users, updating shipment locations, and handling operational settings.

Swift is built to provide a simple and practical workflow for logistics operations while remaining suitable for deployment on shared hosting, cPanel, VPS, or dedicated servers.
